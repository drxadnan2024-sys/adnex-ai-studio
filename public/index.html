🛠 Setup checklist

  1. Runway Dev account banao aur API key generate karo.
  2. Project folder mein .env.example ki copy bana kar uska naam .env rakho.
  3. .env file mein apni API key paste karo.
  4. Terminal mein npm install aur phir npm start chalao.
  5. Browser mein http://localhost:3000 kholo.

API key ko kabhi public HTML/JavaScript, GitHub repo, ya kisi chat mein paste mat karo. Is starter project ko public deploy karne se pehle login, usage limits, rate limiting aur billing protection add karna chahiye.
